Exercícios de programação e algoritmo (PA) para 1º ano da ETEC.

# Exercícios de Algoritmos em VisualG

Repositório criado para armazenar os exercícios desenvolvidos nas aulas de **Programação e Algoritmos (PA)** utilizando a linguagem Portugol no **VisualG**.

## 📁 Algoritmos Incluídos

* `calculo_macas.alg`: Calcula o valor total a ser pago na compra de maçãs aplicando desconto por quantidade.
* `ordem_crescente.alg`: Compara dois números digitados e exibe-os em ordem crescente.
* `operacoes_basicas.alg`: Executa as quatro operações matemáticas básicas (soma, subtração, multiplicação e divisão) com validação de divisão por zero.

## Como Executar

1. Baixe e instale o [VisualG](http://visualg3.com.br/).
2. Abra o software VisualG.
3. Baixe qualquer um dos arquivos `.alg` deste repositório e abra-o no programa.
4. Pressione `F9` para executar o código.
